# opencv-contrib-python is a superset of opencv-python and is the one that
# actually ships cv2.face (the LBPH recogniser). Installing both side by side
# makes the two cv2 packages shadow each other, so only list contrib here.
# (The old pin, 4.13.0.88, was never published to PyPI.)
#
# Capped below 5. The bare >= resolved to 5.0.0.93, so a fresh install got a
# major version nothing here has been run against while this machine stayed
# on 4.13. Raise the cap deliberately, after checking cv2.face still behaves,
# rather than by being the next person to install.
#
# Not the -headless build, even on a server: headless ships cv2/data as an
# empty package, with none of the haarcascade XML files, so loading the face
# cascade fails. See the CI workflow.
opencv-contrib-python>=4.13.0.92,<5
numpy
Flask>=2.3

# Tests only, and less optional than they look. `coverage` is what
# tests/test_published_figures.py measures the published figures with, so
# without it that test errors rather than skips -- and CI installs exactly
# this file. pytest-cov is what the documented coverage command asks for.
#
# 7.10 at least: .coveragerc uses `source_dirs`, which is what makes a module
# no test imports show at 0% instead of vanishing from the report. Older
# releases print one warning about the unknown setting and carry on, so the
# floor is what keeps the percentage honest on a fresh install.
pytest>=7.4
coverage>=7.10
pytest-cov>=4.0
